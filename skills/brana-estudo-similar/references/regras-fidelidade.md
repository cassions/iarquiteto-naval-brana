# Regras de fidelidade — prioridade máxima

Estas dez regras valem acima de qualquer outra instrução da skill. Um estudo de
similares existe para dar base numérica a decisões de projeto: se um número está
errado, o casco sai errado. É por isso que aqui vale mais dizer "não encontrei"
do que entregar um valor bonito.

## 1. Nunca responda de memória

Toda afirmação factual — dimensão, potência, ano, estaleiro, material — tem que
vir de uma página que você consultou **nesta conversa**. Se não pesquisou,
pesquise antes de responder. Seu conhecimento prévio serve para saber *onde
procurar* e para julgar se um resultado faz sentido, nunca como fonte.

## 2. Cite apenas o que você abriu

É proibido citar uma URL que você viu só no resultado de busca. Abra a página,
leia, e só então cite. Se não conseguiu abrir, escreva literalmente:
"não consegui acessar [URL]". Não deduza o conteúdo pelo título nem pelo trecho
que o buscador mostrou — snippets de buscador misturam modelos e anos com
frequência.

## 3. Nunca construa URL

Reproduza apenas links que apareceram literalmente na busca ou como link dentro
de uma página que você abriu. Não monte endereço por padrão adivinhado
(`site.com/barcos/modelo-42`), mesmo que pareça óbvio. URL inventada que por
acaso responde 200 é a pior armadilha possível.

## 4. Cada afirmação com fonte, data e link

Formato: `[nome da fonte, data de publicação, link]`. Se a página não tem data
identificável, diga isso explicitamente — não deixe o leitor supor que é recente.

## 5. Fonte primária na frente

Ordem de preferência:

1. Site do estaleiro / construtor — especificação oficial do modelo.
2. Banco de dados náutico especializado (Sailboatdata, TheBoatDB).
3. Revista ou portal náutico com teste/raio-x do barco.
4. Agregador, anúncio de revenda, blog.

Se só existe fonte secundária, diga isso: "não localizei especificação do
estaleiro; o dado abaixo vem de [revista X]".

## 6. Copie os números literalmente

Dimensões, datas, valores, nomes de modelo e citações diretas são copiados
exatamente como estão na página. **Nunca arredonde. Nunca estime.** Se a fonte
diz `41.5 ft`, vai `41.5 ft` para a aba original — a conversão para metros é
feita pela fórmula da planilha, não por você.

Corolário: nunca converta unidade "de cabeça" para mostrar no chat. Se precisar
mostrar em metros antes da planilha existir, calcule e diga qual fator usou.

## 7. Divergência entre fontes se mostra, não se escolhe

Se duas páginas dão comprimentos diferentes para o mesmo barco, apresente as duas
versões, os dois links, e explique a divergência (pode ser LOA com plataforma de
banho versus LOA do casco, ano de modelo diferente, versão de motorização
diferente). Deixe o projetista decidir. A divergência vai para a seção de
observações do documento final.

## 8. "Não encontrei" é um resultado válido

Se a busca não trouxe base sólida, escreva: **"Não encontrei fonte confiável para
isto."** Isso é um acerto, não uma falha. Jamais preencha a lacuna com o que é
plausível para um barco daquele porte. Célula vazia na planilha significa "a fonte
não informa" — e o modelo de planilha já prevê isso.

## 9. Sinalize dado potencialmente desatualizado

Corte: **12 meses**. Se a fonte for mais antiga que isso e o tema muda com o
tempo — preço, motorização de linha, se o modelo ainda é produzido, versão de
equipamento — avise que pode ter mudado. Dimensão de casco de um modelo definido
não muda; preço e motor mudam.

## 10. Verificação final

Antes de fechar qualquer entrega, releia sua própria resposta e, para cada
afirmação, confirme que consegue apontar a página e o trecho que a sustenta.
Apague ou reclassifique como lacuna tudo que não passar.

## Barcos tradicionais e históricos — cuidado extra

Embarcações tradicionais (canoas, saveiros, botes de trabalho, projetos
Herreshoff) frequentemente não têm ficha técnica padronizada. É normal ter só
comprimento e boca. Não complete o resto por analogia com barco moderno: as
proporções são outras. Registre o que a fonte traz e deixe o resto em branco.

## O que fazer quando a fonte é um PDF grande

O acervo da Marinha (Coleção Alves Câmara) é um PDF extenso e digitalizado.
Localize a página específica que trata da embarcação, cite o número da página, e
copie o texto como está — inclusive grafia de época. Se o PDF não abrir ou for
imagem sem texto legível, diga isso em vez de tentar reconstruir o conteúdo.

# Dois exemplos de calibragem

Resumos condensados de casos reais já preenchidos. Servem para calibrar **nível de detalhe** esperado em cada campo — não para copiar. Note como as respostas são específicas e numéricas, nunca "depende" ou "o normal".

---

## Exemplo A — veleiro pequeno, construção amadora, água interior

| Campo | Resposta |
|---|---|
| Uso principal | Lazer em família, pequenos passeios em águas interiores |
| Papel mais importante | Passear com segurança e conforto; velejar sem esforço vale mais que performance |
| Usuário principal | Homem, 25–75, perfil "faça você mesmo"; é o dono e vai pilotar |
| Demais usuários | 5–80 anos, ambos os sexos; família, eventualmente amigos |
| Tripulantes | Média 3; máximo 6 no dia; pernoite 2 adultos + 1 criança |
| Residência | Interior de SP; casa com garagem para 3 carros e edícula para pequena oficina |
| Uso anual | 20 dias/ano, 2 dias seguidos no máximo |
| Região | Rios Tietê e Paraná, interior de São Paulo |
| Clima | Subtropical úmido, 15–33 °C, extremos históricos 11 e 37 °C |
| Vento/ondas | Poucas ondas; vento médio 6 nós, raramente acima de 12; predominante de leste |
| Restrições | Calado máximo 2 m; restrição de altura por pontes e eclusas |
| Derrota | ~20 milhas no Rio Paraná saindo de marina na Ilha Solteira, barco em vaga seca; férias com viagens de uma semana rio abaixo, volta rodoviária |
| Travessia máxima | 60 milhas |
| Orçamento | R$ 50.000 total; R$ 1.500/mês; R$ 3.600/ano de manutenção, feita pelo próprio dono exceto pintura e usinagem |
| Construtor | Amador, sem experiência em barcos, mas marcenaria como hobby |
| Material/método | Compensado naval com epóxi, *screw & glue* |
| Propulsão | Vela — mastro autoportante com retranca *wishbone*; motor de popa auxiliar |
| Requisito de performance | Conforto acima de desempenho; mastro fácil de desmontar por causa de pontes e eclusas |
| Dimensões | LOA 20 ft · Boca 7,5 ft (limitada pela carreta rodoviária) · Calado 0,3 m / 1,5 m com bolina baixada |

**O que este exemplo ensina:** a boca foi definida pelo transporte rodoviário, o calado pela profundidade do rio e a altura do mastro pelas pontes. Restrição vira dimensão.

## Exemplo B — lancha de 35 pés, estaleiro profissional, navegação costeira

| Campo | Resposta |
|---|---|
| Uso principal | Lazer costeiro, passeios de dia com grupo |
| Papel mais importante | Ser confortável mesmo em alta velocidade; espaçoso, com circulação fácil entre ambientes, pé-direito alto e passagens largas por causa da dificuldade de locomoção do dono; privilegiar área externa |
| Usuário principal | Homem, 50–60; dificuldade de locomoção, alto e pesado; é o dono |
| Quem pilota | Marinheiro profissional contratado |
| Demais usuários | 25–50 anos, ambos os sexos; em geral amigos |
| Tripulantes | Média 4; máximo 8 no dia; pernoite 4 (até dois casais) |
| Residência | Rio de Janeiro |
| Uso anual | 20 dias/ano, cerca de 2× por mês, 2–3 dias seguidos |
| Região | Rio de Janeiro a Angra, navegação costeira |
| Clima | Tropical úmido; vento 4–12 nós, ondas até 0,5 m |
| Derrota | Navegação diurna na região de Angra; pernoite a bordo muito eventual |
| Preferências | Em movimento: velocidade e desempenho. Parado: música alta, churrasco e bebida. Hardtop desejado para valorizar revenda; ar-condicionado |
| Orçamento | R$ 750.000 total; R$ 40.000/mês; R$ 50.000/ano de manutenção, feita por marinheiro |
| Construtor | Estaleiro profissional de embarcações semicustomizadas, até 15 m, lanchas cabinadas de alta velocidade |
| Material/método | Fibra de vidro com infusão a vácuo; casco laminado e convés em espuma PVC |
| Propulsão | Motor — Mercruiser 380 hp centro-rabeta |
| Performance | Atingir 40 nós; autonomia de ao menos 300 milhas a 19 nós; conforto relativo em ondas de até 1 m |
| Dimensões | LOA 35 ft · Boca 12 ft 6 in · Calado 3 ft 4 in |

**O que este exemplo ensina:** a limitação física do proprietário virou requisito de arranjo interno (pé-direito, largura de passagem). Característica pessoal do usuário é dado de projeto.

## Contraste entre os dois

| | A | B |
|---|---|---|
| Orçamento | R$ 50 mil | R$ 750 mil |
| Quem pilota | O dono | Marinheiro |
| Quem constrói | O dono | Estaleiro |
| Propulsão | Vela | Motor 380 hp |
| Restrição dominante | Rasa e pontes | Conforto em velocidade |

Mesmo formulário, respostas de ordens de grandeza completamente diferentes. Não empurre o projetista para nenhum dos dois perfis — descubra qual é o dele.
